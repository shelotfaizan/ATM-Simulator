# 🏧 ATM Simulator

A simple **ATM Simulator** built with Python. This project simulates basic ATM and banking operations through a simple command-line interface.

## 🚀 Features

* 🔐 PIN authentication
* 💰 Check account balance
* 💵 Deposit money
* 💸 Withdraw money
* 🚪 Exit the ATM
* ⚠️ Basic validation for incorrect inputs and insufficient balance

## 🛠️ Technologies Used

* **Python**
* **Git & GitHub**

## ▶️ How to Run

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder:

```bash
cd atm-simulator
```

3. Run the Python program:

```bash
python main.py
```
